How to Redeem

Use an 8-character code generated on this site to look up and install a PS4 package.

01
Get a code

Go to the Generator tab, paste a GitHub Release URL or direct .pkg link, and generate a code.

02
Enter it here

Type or paste your 6-character code into the field above and press Redeem Code.

03
Install on PS4

Open the Orbis Store app on your PS4, navigate to Redeem, and enter the same code to start installation.

Orbis is open-source — contribute on GitHub.
